APEX HOLDINGS OMS — V37 DASHBOARD & ANALYTICS UI UPDATE

- Replaced four separate dashboard mini-charts with one combined multi-series line chart.
- Sales, Profit, Expenses and Delivered Sale Quantity (PCS) use separate colors and can be toggled independently.
- Chart supports default last 15 days and manual date range; Owner company filter retained.
- Dashboard See More opens the Sales, Profit & Expense Analytics page.
- Added Sales, Profit & Expense Analytics menu entry between Staff and Settings for Owner/Admin.
- Added report-table mode buttons: All, Profit only, Expenses only. Search/date filters remain available.
- Moved the Company Commission card to the dashboard bottom and simplified it to Month + Commission columns.
- Existing stock item cost is used as the default product cost/expense basis when no master cost has been saved; per-PCS and pack-tier overrides remain available in Product Cost & Pricing Master.
- Existing order/accounting records and previous V36 features retained.
