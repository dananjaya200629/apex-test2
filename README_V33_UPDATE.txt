APEX HOLDINGS OMS V33 UPDATE

1. Shipped page Waybill Layout 1 and Layout 2: Customer Phone 1 / Phone 2 now print at the same 13px font size as the customer name.
2. Add Return: Recently Added Returns is a session-only list. It appears after adding a return in the current session, but is hidden after a browser/page refresh. All return records remain saved in Returned List.
3. Pending Orders: Edit Order now correctly restores each saved item productId into the editor id field. Existing products stay in the form when customer details are edited. Products can still be removed or changed. Stock validation includes the quantity reserved by the original pending order, and stock is adjusted only after a valid update.

The original OMS files and stored data structure are retained.
