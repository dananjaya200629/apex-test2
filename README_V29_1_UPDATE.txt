APEX HOLDINGS OMS V29.1 UPDATE

Updates included in this package:
- New Order customer history now checks Contact Number 1 and Contact Number 2, normalizes Sri Lankan +94/local formats, and shows an Add Data button when matching previous orders are found. Add Data fills customer name and address (and town / city and missing contact fields) from the latest matching order.
- Waybill layouts 1, 2 and 3 include a compact outlined Product / Color / Size box beneath customer details without changing existing waybill labels.
- Owner Announcement supports MP4/WebM/OGG clips up to 30 seconds, manual scale from 50% to 200%, drag-to-reposition image/video crop, and drag-to-arrange banner content in the live preview.
- Announcement banner is hidden on New Order and Shipped List pages.
- Countdown typography/theme styling refined.
- Bundled Inter and Sinhala fonts are explicitly registered for clearer system typography.
- Lead List rows use light green for Confirmed, light yellow for No Answer, light red for Rejected, and white/default for Pending.

Start with start_server.bat (Windows) or start_server.sh (Linux/macOS) as usual.
