APEX HOLDINGS OMS V32 UPDATE

1. Shipped page: Waybill Layout 1 and Layout 2 now print the customer address at the same font size as the customer name.
2. Waybill Layout 1 and Layout 2: the former fixed footer identifiers are replaced with the actual product code(s) belonging to the order.
3. Announcement: uploaded image/video remains visible as the banner background; headline, scrolling text and countdown timer render above the media. No dark overlay is added. The live preview is moved to the top of the banner editor. Existing image/video scale and crop controls now apply to the banner preview and published banner.
4. Add Return: type a single waybill number and press Enter to add it. Recent returned waybill, product, price, quantity and date rows appear underneath the input.

Existing database files and application settings are preserved.
