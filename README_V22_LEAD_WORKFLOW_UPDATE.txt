APEX HOLDINGS OMS — V22 LEAD WORKFLOW UPDATE

V22 includes:
- Lead List defaults to today’s leads plus older Pending leads only. Choose a Start/End Date to review historical leads of any status.
- Every company's admin/staff view is restricted to leads for that company; imports save only to the selected company.
- Owner imports choose a company; Company Admin imports automatically target their own company.
- All imported rows must be assigned to a company Sales/Shipping user before import; no unassigned import action is provided.
- Lead List sorts Pending, No Answer, Rejected, Confirmed (the internal legacy OK status is shown as Confirmed).
- Select multiple leads and use the single Reassign Selected button to assign them to one user within the same company; delete multiple selected leads from the top action bar.
- Company comparison chart has per-company toggles below it.
- Defines the missing lead sorting comparator that could stop the Lead List table rendering.

Import file headers: Customer Name, Address, Contact No, Contact No 2, Other, Product Code.
