APEX HOLDINGS Cloud OMS — Commission/Search Refinement Update

Changes in this build:
1. Commission moved under Company dropdown for Owner/Admin only; it is not under Staff.
2. Company commission page shows January–December monthly rows. Admin sees only their own company commission; Owner sees all company rows. Owner uses a Paid button to mark paid, no Done/Complete button.
3. Staff Commission Rate page lets Company Admin set commission per order (default Rs.45) and per delivered order (default Rs.75). Current-month staff calculations are automatic from order/delivered counts.
4. Search Orders now defaults to all historical orders. Owner/Admin can filter by date range, staff, status and keyword. Staff users see only their own orders.
5. Order status filter supports Act (Pending), Shipped, Delivered and Returned (plus OK for legacy data).

Standalone build. No WordPress dependency.
