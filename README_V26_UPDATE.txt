APEX HOLDINGS OMS — V26
1. Lead List: the top filter card is now one slim row (status, user, dates, search) with small quick-range buttons.
2. Fonts: plain, normal system fonts everywhere (Segoe UI / Arial; Sinhala falls back to Nirmala UI / Noto Sans Sinhala which is bundled).
3. New Order: the town/city box lists 800+ Sri Lankan towns in A-Z order as soon as you click it (type to narrow the list).
4. Settings > Language: English / Sinhala / Tamil now translate the WHOLE system (menus, page titles, labels, buttons, table headings,
   placeholders, messages and confirmations). Switching is instant and reversible. Names, addresses and other data you type are never translated.
5. Shipped List > Layout 3 is now the layout from your waybill_3.pdf (COD WAYBILL + amount box, To / Product / From boxes).
   6 waybills per A4 page, extra waybills continue on the next page, long names/addresses shrink automatically so nothing is cut off.
6. Orders: a manual order goes to Pending Orders; an order created from a lead returns to the Lead List.
7. New Order: the Order Note card moved below Customer History. "Save Note" stores the note on the lead; the Lead List Note column shows
   a button - click it to read / edit the note in a pop-up. The note is never printed on waybills.
8. Ship page: Select 10 / 20 / 50 are small buttons grouped together.
Also included from v25: live updates between users (run start_server), owner receipt viewing, approve/reject buttons, company edit/block/delete.
