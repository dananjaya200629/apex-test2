APEX HOLDINGS OMS V40 — UPDATED FEATURES

- Product Master label changed from “Inbound Delivery Charge” to “Delivery Charge”.
- Sales, Profit & Expense Analytics chart includes Sales, Profit, Expenses and Sale Quantity (PCS), each with an independent color and toggle.
- Curved trend lines and horizontal date labels shown as month/day (MM-DD); metric scales are independently normalized so PCS remains visible alongside currency metrics.
- Dashboard Shipped KPI counts individual orders with Shipped status, not shipment batches.
- Profit is recognized only for Delivered orders. Shipped and Returned orders retain sale value in Sales; Returned accounting excludes item cost and retains delivery/other expenses.
- Company creation requires Company Name, Manager Name with initials, Company Address and Phone; optional document upload is available.
- Owner Company List has a company information icon to view company manager, address, phone, admin login and attached document.
- Staff/Sales/Shipping users receive a private Staff Dashboard showing their own order count, confirmation rate, delivered rate, return rate and colorful status/rate donut charts. Settings remains accessible to staff.
- Existing V39 data and other OMS modules are preserved.
