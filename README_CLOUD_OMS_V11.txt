APEX HOLDINGS CLOUD OMS v11

Updates in this build:
- Profit & Sales Trend panel visible to Owner and Company Admin only.
- Company Admin sees only their own company; Owner can select a company.
- Start Date / End Date filter updates the chart immediately.
- Sales is a solid curved line; Profit is a dashed curved line.
- Settings page is available to every user with Light/Dark Mode controls.
- Full-system theme switches immediately.
- New Order has an optional Color / Size field, stored on the order and shown on waybills.
- Contact number is required for new orders.
- 2560x1440 logistics-themed login background included.

Important: this package remains a standalone browser/localStorage OMS. It is cloud-branded/cloud-ready UI, not a true multi-device cloud database. For real multi-user cloud synchronization, deploy a backend/database and authentication service.
