APEX HOLDINGS OMS — V29 Announcement & Waybill Update

OWNER ANNOUNCEMENT STUDIO
- Banner Headline and Animated Scrolling Text each have independent font, size, color and bold controls.
- Supports poster/banner images and MP4, WebM or OGG video clips. Uploaded video clips autoplay muted and loop.
- Manual scale, horizontal-position and vertical-position controls adjust the media crop in the banner.
- Includes a simple sizing guide. Recommended image size is approximately 1600 x 450 pixels; video upload limit is 25 MB.
- Countdown label is editable. Six timer appearances are available: Glass, Pill, Square, Circle, Minimal and Neon.
- Multiple saved banners are listed below the editor. Each can be turned on/off independently, and enabled banners rotate one per minute.
- Media is uploaded to the OMS server's uploads/announcement folder instead of being embedded in shared state, so video files do not exhaust browser localStorage. Keep the OMS server and uploads folder available while users view banners.
- Legacy single-banner settings are migrated into the saved-banners list.

WAYBILL LAYOUT 1 & 2
- Only a small, thin-outline Color / Size box was added beneath customer details. Existing layout elements, dimensions and visual styling remain otherwise unchanged.

The main site font has not been changed. The font controls apply only to the banner headline and scrolling text.
