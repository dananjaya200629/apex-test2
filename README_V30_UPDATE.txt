APEX HOLDINGS OMS — V30 UPDATE

- Pending Orders now shows customer, address, both phone numbers, product, price, status and row-level Edit/Delete actions.
- Pending order edits are saved back to the same order; Update returns to Pending Orders and refreshes the saved table.
- Deleting a pending order restores its reserved stock quantity.
- Waybill product details show Product, Color and Qty (no Size label); long text is clipped/wrapped within each waybill box.
- Announcement editor supports company targeting, 10 countdown themes, time-only countdown display, draggable crop positioning and eight resize handles for media scale.
- When opened directly as a local file, a small video clip (under 2 MB) can be saved into the browser without starting the OMS server. When using the server, supported media uploads remain under 25 MB.
- Announcement banner remains in normal page flow at the top rather than staying sticky while scrolling.

Notes: Direct-file video storage is limited by browser localStorage capacity. For reliable persistent shared media, use the existing server-based OMS workflow.
