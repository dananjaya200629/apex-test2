APEX HOLDINGS OMS — V27
1. Add Return: type or scan waybill / tracking numbers (one per line or comma separated, e.g. WB-5001). Each order becomes "Returned"
   and its stock is added back to the company automatically. Shows "Return Added Successfully" plus a list of what was returned and
   what was not (not found / already returned / not shipped yet).
2. Returned List: shows the date and time of each return. Default view = today's returns; pick Start/End dates (or Last 7 / 30 days / All dates)
   to see older returns. Search by order, tracking, customer or product.
3. Company Admin can edit and delete the staff of their own company (Staff > Staff List). Deleting a staff member moves their leads to the Admin.
4. Admin can change his own name and phone (Staff List > Edit My Name); the company name stays unchanged. The Owner can still edit any login.
5. Lead import / Reassign: the company Admin appears in the user list, so leads can be assigned to the Admin account too.
Everything from v26 (Sinhala/Tamil, waybill layout 3, live updates with start_server, etc.) is included.
